# Shader pack'ler

Minecraft 1.20.1 ile uyumlu shader `.zip` dosyalarını bu klasöre koyup GitHub'a
gönder. Launcher seçilen arşivi oyunun `shaderpacks/` klasörüne indirir.
Shader kullanmak için Forge ile uyumlu Oculus gibi bir shader yükleyicisi gerekir;
oyunda Video Ayarları ekranından shader'ı seç.
